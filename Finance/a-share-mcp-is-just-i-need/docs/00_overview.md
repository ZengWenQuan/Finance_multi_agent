# 概览

我们的 MCP 服务器是围绕数据源代码的一层薄封装。它通过 MCP 暴露工具（函数），
让 LLM Agent 能够请求市场数据并得到结构化结果。

核心目标：
- 工具名称与入参保持稳定
- 传输层、工具注册层、数据访问层清晰分离
- 区分“无数据”与“真实错误”的一致化异常处理

高层流程：
1. 客户端启动 MCP 服务器（本地 `stdio` 或远程传输）。
2. 服务端注册工具与输入输出 schema。
3. 客户端携带参数调用工具。
4. 服务端调用数据源实现。
5. 服务端返回结构化结果或结构化错误。

代码入口：
- `mcp_server.py`（服务端启动与工具注册）
