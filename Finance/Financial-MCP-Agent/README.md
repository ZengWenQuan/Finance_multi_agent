# Financial MCP Agent

`Financial MCP Agent` 是一个面向 A 股金融分析场景的多智能体应用系统，结合了 `MCP`、`LangGraph`、`RAG`、`Graph RAG` 和本地持久化存储，用来完成股票分析、报告生成、会话问答和结果沉淀。

项目的目标不是单纯做一个聊天机器人，而是做一个可以持续工作、可追踪、可扩展的金融分析助手系统。

## 项目定位

这个项目主要服务于两类任务：

1. 面向单次分析任务的多维度股票研究
2. 面向会话场景的结果复用与问答追踪

它会围绕一只股票或一个公司自动完成：

- 基本面分析
- 技术分析
- 估值分析
- 新闻分析
- 综合报告汇总

同时，系统还支持基于已生成分析结果的二次聊天问答。

## 总体设计

项目采用的是“分析工作流 + 检索增强 + 持久化存储”的整体架构。

### 1. 多智能体分析层

系统把金融分析拆成多个专门 agent：

- `fundamental_agent`
- `technical_agent`
- `value_agent`
- `news_agent`
- `summary_agent`

每个 agent 负责自己的一块分析内容，最后由总结 agent 汇总成完整报告。

### 2. 工具接入层

项目通过 `MCP` 接入外部金融工具和数据源，让 agent 能调用真实的市场数据、财务数据和分析接口，而不是只依赖模型记忆。

### 3. 检索增强层

项目同时使用两类检索思路：

- 传统向量检索，用于按语义召回相关文本
- 图检索，用于组织实体关系和主题关联

这使得系统不仅能“找资料”，还可以“利用资料之间的关系”。

### 4. 持久化层

系统把会话、agent 结果、综合报告和聊天记录持久化到本地数据库和存储文件中，便于后续追踪、复用和评估。

### 5. Web 与 CLI 双入口

项目既支持命令行交互，也支持 Web 后端服务和前端页面，适合本地调试和服务化部署。

## 核心功能

### 金融分析

系统能够对 A 股公司做自动化分析，覆盖：

- 财务和基本面
- 价格趋势和技术指标
- 估值水平
- 新闻与风险信号

### 综合报告生成

系统会把多个 agent 的结果整合成一份综合性的分析报告，作为面向用户的主输出。

### 会话式问答

在一次分析完成后，用户可以继续基于同一会话追问，系统会结合已有报告、agent 结果和检索上下文回答问题。

### 结果沉淀

分析结果和聊天记录会被保存下来，便于后续查询、复盘和扩展。

### RAG / Graph RAG 支持

项目支持两条增强路径：

- `C8 Hybrid RAG`
- `C9 Graph RAG`

前者偏向向量检索与结果复用，后者偏向图结构关系与多跳关联。

### 评估能力

项目内置了 RAG 评估脚本，可以对检索效果和回答质量做回归验证。

## 主要技术栈

- `FastAPI`：后端服务
- `LangGraph`：多智能体工作流编排
- `LangChain`：LLM 与工具调用集成
- `MCP`：外部金融工具接入
- `SQLite`：会话与结果持久化
- `FAISS`：向量检索
- `Neo4j`：可选图存储后端
- `DeepEval`：RAG 评估

## 系统数据流

一个典型请求大致会经历以下流程：

1. 用户提交自然语言问题
2. 系统识别公司名或股票代码
3. 多个分析 agent 并行执行
4. 系统调用外部工具获取数据
5. 生成各自分析结果
6. 汇总成最终报告
7. 持久化到数据库和本地文件
8. 后续聊天在已有上下文基础上继续回答

## 目录结构

项目主目录中比较重要的部分如下：

- `src/`：核心后端代码
- `frontend/`：Web 前端页面
- `deploy/`：Docker 和部署脚本
- `docs/`：设计说明和技术文档
- `test/`：测试和评估脚本
- `data/`：本地数据库和存储文件

## 关键模块

### `src/main.py`

命令行入口，负责发起整套金融分析工作流。

### `src/main.py` 之外的后端服务

Web API 入口，负责 session 创建、解析、分析、报告和聊天接口。

### `src/services/analysis_service.py`

承载分析流程、默认存储、向量服务和图存储的初始化逻辑。

### `src/services/chat_service.py`

负责会话式问答，把已有报告、agent 输出和检索上下文组装成回答。

### `src/persistence/`

负责 SQLite 会话存储、图存储和相关 schema。

### `src/agents/`

各个金融分析 agent 的实现。

### `src/tools/`

MCP 客户端、工具映射和配置。

## 设计特点

### 1. 职责拆分清楚

把基本面、技术面、估值、新闻和总结拆成独立 agent，降低单个模块复杂度。

### 2. 支持真实工具调用

通过 MCP 接入外部数据源，让分析更贴近真实市场信息。

### 3. 支持结果复用

分析结果不是一次性输出，而是可以进入后续问答和报告检索。

### 4. 支持多种增强方式

项目同时保留了向量 RAG 和图 RAG 的入口，方便按场景升级。

### 5. 支持评估与回归

RAG 相关流程可以通过 DeepEval 和本地召回脚本做质量检查。
